# Memorie — Privacy Policy

The privacy policy for the Memorie iOS app, published at
<https://srinidhi1222.github.io/memorie-privacy/>.

This repository is public because the App Store requires both the policy and a
support page to be reachable at public URLs. It contains those two pages and
nothing else — the app's source is not here.

    index.md     the privacy policy   /memorie-privacy/
    support.md   the support page     /memorie-privacy/support.html

Edit either and push; GitHub Pages rebuilds within a minute or two.
